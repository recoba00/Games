## 설계 보완

처음 제안한 음식 픽셀만의 flood fill은 떨어져 있는 장식 조각을 별도 조각으로 잘못 세며, 곡선 끝점 처리도 불명확했다. 투명 배경을 포함한 전체 영역의 label map을 생성하고 면적에는 음식 알파만 합산하도록 수정했다. 끝점은 음식 픽셀을 통과하지 않는 투명 경로로만 외부에 연결한다. 판정과 분리 렌더링이 동일 label map을 사용한다.

## 구현 판단과 범위

- 수치가 없던 재화 기본값은 설계서에 명시했다. 게임 시작 하트 차감을 추가하지 않고 실패 이어하기에 사용한다. 판정 전 마지막 선도 취소할 수 있도록 명시적 판정 버튼을 추가했다.
- 구멍에서 끝나 조각을 나누지 못한 열린 슬릿·미완성 선은 횟수를 소비하지 않는다. 완전히 닫힌 고리는 허용한다.
- 기존 PWA의 테스트 초기화 차단을 유지했다. 웹·토스에서도 빌드 ID 변경으로 유저 재고가 자동 초기화되던 동작을 제거했다.
- Windows 빌더에 UTF-8 및 실행 파일 경로 처리를 명시하고 토스 package-lock의 버전을 맞췄다. 기존 개발용 시뮬레이터의 선 입력도 경로 형식으로 맞췄다.
- 최초 구현 시 제한된 실행 환경에서 상위 Git 탐색이 실패하여 파일 변경과 빌드 산출물로 전달했다. 후속 commit/push/deploy 요청에서 상위 `Games/.git` 저장소(`recoba00/Games`, `main`)를 확인했으며, 기존 저장소로 커밋·푸시하고 기존 GitHub Pages 및 Vercel 프로젝트에 배포한다. Git 초기화나 새 배포 프로젝트 생성은 필요하지 않다.
- 실제 토스 앱/실광고는 이 로컬 검증 범위 밖이다. 광고 결과 처리는 모의 done/closed/error로 확인했다. 기존 광고 그룹·포인트 프로모션 등 미연결 SDK 설정은 기존대로 남아 있다.
