# 사업팀 게임 흐름 수정 계획

**목표:** 사용자가 전달한 7개 재요청을 기존 Canvas/순수 JS 게임과 웹·토스·PWA 공통 소스에 반영한다.

**범위와 결정:** 직선 기본값, 취소 자리에 무료 직선/곡선 전환(선택 저장), 마지막 유효 선 이후 자동 판정. 하트·상점·클리어 코인 제거. 아이템 3종의 기존 재고와 코인은 보존하고, 재고 0개일 때 기존 가격(도우미 30/스탑워치 20/돋보기 30코인) 또는 보상형 광고 완료로 즉시 사용. 아이템 선택/광고 중 시간 정지, 닫기/실패/취소 시 무차감, 중복/오래된 광고 완료 방지. 기존 5판 반복 미션의 1P에 코인 10개 추가(기존 수령 방식·일일 10회 제한 유지). 하트 관련 저장 필드는 이관 시 제거한다. 첨부 이미지가 없어 기존 UI 스타일로 전환 버튼을 만든다. 외부 배포는 포함하지 않는다.

## 진행 기록

- 기존 원본·테스트·빌드 확인. 구현 시 상위 경로의 Git 조회가 실행 권한 제한으로 실패해 소스를 직접 갱신했다. 후속 커밋·배포 요청에서 허용된 실행 권한으로 상위 `Games` 저장소와 `main` 브랜치를 확인했다.
- 기존 구현에서 새 경제 테스트 3건이 예상대로 실패한 뒤 구현하여 통과했다. 일반 실행의 브라우저 드라이버는 로컬 소켓 권한으로 멈춰, 허용된 실행 권한으로 브라우저 테스트를 수행했다.
- 최종 독립 코드 검토에서 추가 중대 결함은 없었다. 아이템 광고 중 백그라운드 전환 후 완료 → 화면 복귀 시 이전 일시정지가 남는 문제를 발견해, 재현 테스트 실패를 확인한 뒤 복귀 상태를 보완했다.
- 최종 검증: Node 8/8, 실제 Edge 게임 통합 19/19, PWA 오프라인·기존 저장 이관 1/1 통과. 음식 50종의 2·3·5·7등분 가이드와 실제 포인터 곡선/직선, 광고 결과/재진입, 미션 잔여 보상/일일 한도/날짜 초기화를 포함한다.
- 화면 확인: 360×640, 375×812, 844×390. `bb/tests/screenshots/business-revision-{play,item,mission}.png`에 최종 화면을 저장했다. 시간·단계 UI는 기존보다 40 논리px 위로 이동했다.
- 최종 빌드: `bb/dist/`, `ait/dist/`, `ait/hanipcut.ait`, `pwa/dist/`, `pwa/hanipcut-pwa.zip`. 버전 0.11.0, 배포 대상 PWA 캐시 ID `0.11.0-82138bea24966d52`. 토스 실제 광고 ID 등 기존 미연결 값은 유지하며, 광고 결과는 웹 테스트 광고와 SDK 경계 대체 응답으로 검증했다. 최초 구현 단계에서는 외부 배포를 수행하지 않았다.
