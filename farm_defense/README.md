# 텃밭 지키기 (farm_defense)

숲에서 내려오는 동물을 수비대(허수아비·진돗개 …)가 자동으로 쫓아내고, 쫓아낸 동물이 남긴 채소로 수비대를 키우는 방치형 디펜스. 타깃은 50~60대 여성, 토스 미니앱 + 웹.

- 현재 버전: **v0.1.0** (`src/game.js`의 `CFG.version`) — M1 전투 프로토타입
- 엔진 없음: HTML5 Canvas 2D + 순수 JS (한입컷과 같은 방식)
- 기획서: 텃밭 지키기 — 방치형 디펜스 게임 기획서 (Claude Docs)

## M1에 들어간 것
- 동물 2종(참새·토끼) + 10스테이지마다 멧돼지 대장(졸개 6마리 동행)
- 수비대 2종: 허수아비(처음부터, 지푸라기 던지기) · 진돗개(스테이지 3부터 고용, 짖기)
- 스테이지 진행, 울타리가 무너지면 한 단계 뒤로 물러나 자동 반복 (게임오버 없음)
- 채소 · 강화(1번/10번/최대) · 달성 보너스(25/50/100/200레벨 힘 2배)
- 훠이: 전장을 누르면 근처 동물을 함께 쫓음, 꾹 누르면 반복
- 저장(브라우저 localStorage) · 다녀온 사이 수확(최대 8시간, 50%)
- 임시 그림: 캐릭터는 모두 코드로 그린 도형 (아트가 오면 교체)

아직 없음: 수비대 6종·동물 4종, 농기구, 새 밭 일구기, 새참(광고), 공통 메타(출석·할 일·알림), 토스 연동, 소리.

## 구조
```
src/
  index.html      화면 뼈대 (빌드 때 css·js가 들어감)
  style.css       글자 18px+, 버튼 56px+ 기준
  game-core.js    공식 · 수비대/동물 데이터 · 전투 엔진 (DOM 없음, node에서 그대로 실행)
  game.js         그리기 · 입력 · 목록 · 팝업 · 저장
tests/            node 테스트
sim.js            밸런스 시뮬레이션 (방치만 했을 때 진행 속도)
build.py          웹 빌드 → dist/index.html (파일 하나)
```
숫자(체력·보상·비용·속도)는 전부 `game-core.js` 위쪽 `F`, `DEFENDERS`, `ANIMALS`에 모여 있습니다.

## 빌드 · 실행
필요: Python 3, Node.js 18+
```bash
python3 build.py          # → dist/index.html
```
`dist/index.html`을 브라우저로 열면 바로 플레이됩니다 (휴대폰 세로 화면 기준).

## 테스트
```bash
node --test tests/game-core.test.cjs   # 공식 · 강화 · 저장 정리 · 숫자 표기 · 실제 전투 (12개)
node sim.js 60            # 60분 방치 시뮬레이션: 스테이지 도달 시각, 물러난 횟수
```
- 주소 뒤 `?reset=1` → 저장을 지우고 처음부터

## ⚠ 출시 전에 지울 테스트 코드
| 위치 | 내용 |
|---|---|
| `src/game.js` 맨 아래 `window.__farm` | 개발용 콘솔 접근 |
| `src/game.js` 위쪽 `?reset` 처리 | 웹 테스트용 초기화 |
